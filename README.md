# AWS Cloud Automation & Serverless Data Processing

## Overview

This project demonstrates practical implementation of serverless data processing using Amazon Web Services.

The solution combines Amazon S3, AWS Lambda, IAM, EventBridge and CloudWatch to automate processing of CSV datasets.
