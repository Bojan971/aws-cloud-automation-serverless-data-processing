# Case Study Overview

## Project Goal

The objective of this case study is to demonstrate practical knowledge of AWS serverless technologies and automated cloud data processing using Python.

---

## Technologies

- AWS Lambda
- Amazon S3
- IAM
- EventBridge
- CloudWatch
- Python
- Pandas
- Boto3

---

## Main Features

- Read multiple CSV datasets from Amazon S3.
- Merge datasets into a single DataFrame.
- Extract metadata.
- Generate aggregated statistics.
- Upload processed results back to Amazon S3.
- Serverless execution.
- Cloud-based automation.

---

## Repository Structure

The repository is organized into logical folders separating source code, documentation, architecture diagrams and screenshots.

This repository is intended for recruiters, hiring managers and technical interviewers interested in reviewing practical AWS Cloud and Python automation skills.
